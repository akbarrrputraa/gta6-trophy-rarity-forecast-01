Forecasts each GTA VI PS5 trophy's Exophase earn rate a week after launch, as five quantiles, from the house's reads of the trophy page: a two-sided log-time model of earned counts and players tracked, fit on the recent window, so launch-week deceleration is respected and dilution is modelled instead of extrapolated away.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
